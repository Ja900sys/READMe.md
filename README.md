
<h2> Incident Ticket Managment  </h2>
<h3>Objective and scope: </h3>

•	To develop web applications that allow users to update, track, and create incident tickets. 

•	Ticket creation management

•	Ticket life cycle tracking

•	Ticket search and filtering

•	Comments and updates

•	Integrating database

•	Documentation and testing

•	Ai assistance features

<h3> Process: </h3>

•	Frontend Development: Creates/edits/update tickets and more

•	Collaboration: Working effectively as a team and assigning jobs to suitable co-Interns.

•	Backend Development: Implement API’s and integrate Database

•	Quality assurance and Testing: Improving accessibility and resolves issues/defects, improve usability and performance 

•	Enhancements: Search and filtering system, Add AI assistant

•	Documentation: document any limitations, User Guide, Maintain README/User Guide 

<h3> Functional requirements: </h3>
•	Create Incident Ticket 

•	View  list of tickets that the Users have created

•	View details 

•	Edit ticket Info

•	Update Ticket status 

•	Close or open a ticket

•	Activity Tracking; track history, add comment/notes 

•	AI features 

•	Dashboard Displays like status or trends 

•	Search and Filtering

•	Comments and Update 

•	AI Assistance 

•	Each Ticket should Include: Ticket ID, Title, Requester Information, Description, Subject, Category, Priority, Status, Created Date, Last Update Date
